Universal Embeddable AI Assistant

Embed Your AI Assistant Anywhere

This simulates an external customer website (e.g. your WordPress site, Shopify store, portfolio, or SaaS app). The AI assistant button floating in the bottom-right corner was embedded with just one single script tag!

The 1-Line Embed Code

Simply paste this snippet before </body> on any webpage:

<!-- NexusAI Drop-in Widget -->
<script 
  src="http://localhost:8000/widget.js" 
  data-api-url="http://localhost:8000"
  data-title="NexusAI Assistant"
  data-color="#2563eb"
  defer>
</script>

Key Advantages

  • Shadow DOM Isolation: Host website CSS will never mess up your chat styles.
  • Direct Local / ngrok Inference: Communicates via streaming SSE directly with your local Ollama models.
  • No Cloudflare Dependency: Host it on your own server, VPS, or tunnel.
